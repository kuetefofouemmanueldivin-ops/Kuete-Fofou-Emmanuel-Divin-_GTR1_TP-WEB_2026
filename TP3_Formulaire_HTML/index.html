Introduction

Ce mini-site a été creé dans le cadre du cours de TP Programmation Web.

il permet de decouvrire la création de plusieurs pages HTML reliée entre elles

Objectif du mini-site

L'objectifs est d'apprendre à structurer un petit projet web avec plusieurs fichiers.

Pages disponibles

  • La page Accueil présente le contexte général du mini-site.
  • La page présentation contient les informations personnelles de l'étudiant.
  • La page contact contient les information de contact de l'étudiant.

J'apprend la programmation web parce qu'elle me permettra de creé des interfaces utiles pour les services réseau et les applications d'entreprise.
